What is ShopCore API?

ShopCore API is a RESTful backend service for an e-commerce platform. It handles user accounts, product catalogues, shopping cart operations, payment processing, and order fulfilment.

Built for multi-tenant SaaS deployments, it serves both a consumer-facing web app and a merchant admin panel.

Node.js TypeScript Express 4 PostgreSQL Redis Docker
Main Components
🔐AuthenticationJWT, sessions, OAuth
👤UsersProfiles, roles, preferences
💳PaymentsStripe integration, webhooks
📦OrdersCart, fulfilment, history
📣NotificationsEmail, push, SMS
🔍SearchProduct & order search
🏪CatalogueProducts, categories, stock
Request Flow
Client (Web / Mobile) │ ▼ API Gateway (Express Router) │ ├── /auth/* ──► AuthService ├── /users/* ──► UserService ├── /orders/* ──► OrderService ├── /payments/*──► PaymentService ├── /catalogue/──► CatalogueService └── /search/* ──► SearchService │ ▼ PostgreSQL + Redis Cache

Getting Started
1. Clone & Install
git clone https://github.com/org/shopcore-api cd shopcore-api npm install
2. Environment Setup
cp .env.example .env # Edit .env with your local values: # DATABASE_URL=postgresql://localhost:5432/shopcore # REDIS_URL=redis://localhost:6379 # JWT_SECRET=your-dev-secret # STRIPE_KEY=sk_test_...
3. Database Setup
npm run db:migrate npm run db:seed # optional — loads demo data
4. Run Locally
npm run dev # starts on port 3000 with hot reload npm run test # runs full test suite npm run test:watch # watch mode
⚠️ Traceon found: README setup instructions are partially outdated — Docker Compose steps reference a removed service. Use npm run dev instead.
First Day Guide
1
Read the Project Overview
Understand what ShopCore API does and who uses it. Start with README.md and docs/ARCHITECTURE.md.
2
Run the Application
Follow the Getting Started guide. Confirm the API is running on port 3000 and health check returns 200.
3
Explore Authentication
Authentication is the gateway to everything. Read src/services/authService.ts and try the login endpoint.
4
Review the API Routes
Open src/routes/index.ts to see all endpoints. Refer to docs/api/openapi.yaml for the full spec.
5
Run the Test Suite
Run npm test — all 127 tests should pass. Familiarise yourself with Jest test patterns used in this project.
6
Study the Payment Module
Payments is the most business-critical area. Read src/services/paymentService.ts carefully before making any changes here.
7
Pick a Beginner-Friendly Issue
Check the maintenance list for low-severity issues. Suggested first issue: extract shared email validation utility.
