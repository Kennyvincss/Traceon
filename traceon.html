How it works

Security

Built to be trusted with your code

Read-only

Traceon never commits, pushes, opens pull requests or changes settings.

No tokens in your browser

GitHub credentials stay on the Traceon server. Your browser only holds a secure session.

Secrets untouched

Real .env files are never read. Only variable names from templates are checked.

You stay in control

Signing out revokes Traceon's access token on GitHub immediately.

FAQ

Questions, answered

Can Traceon change my code?

No. Traceon only asks GitHub for read access to repository contents and metadata, and it never sends write requests.

Which repositories can Traceon see?

Only the ones you choose when you install Traceon on GitHub. You can add or remove repositories at any time in your GitHub settings.

Do I need to create a token?

No. You sign in with GitHub like any other app. Traceon keeps the resulting credentials on its server, never in your browser.

Does Traceon run my tests?

No. Traceon analyses code without executing it. Test figures show which files your tests import, and the Testing page gives you the command to run them yourself.
