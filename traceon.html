HOW IT WORKS

From sign-in to findings in three steps

1

Continue with GitHub

Approve Traceon on GitHub's own sign-in page. There is no token to create or paste.

2

Choose repositories

Pick exactly which repositories Traceon may read. Change your choice any time on GitHub.

3

Analyze

Traceon reads a snapshot of the branch and fills every page with your project's real data.

SECURITY

Built to be trusted with your code

Read-only

Traceon never commits, pushes, opens pull requests or changes settings.

No tokens in your browser

GitHub credentials stay on the Traceon server. Your browser only holds a secure session.

Secrets untouched

Real .env files are never read. Only variable names from templates are checked.

You stay in control

Signing out revokes Traceon's access token on GitHub immediately.
